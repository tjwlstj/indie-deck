# 게임 썸네일과 스토어 이미지

현재 소스 기준 기능이다. 배포 여부와 사용 가능한 버전은
[GitHub 릴리즈](https://github.com/tjwlstj/indie-deck/releases/latest)에서
확인한다. 썸네일 탐색은 게임을 실행하거나 게임 파일을 수정하지 않는다.

게임 상세의 **이미지 작업**에서 **내 이미지 선택**이나 **게임 폴더에서 선택**을
고르고 실행하면 PNG·JPEG·WebP 파일을 직접 선택할 수 있다. 표지 영역에 이미지
파일 하나를 끌어다 놓아도 된다. 파일은 2 MiB 이하, 한 변 8,192픽셀 이하,
총 2,400만 픽셀 이하여야 한다. 게임 폴더에서 선택은 파일 창의 시작 위치만
게임 폴더로 지정하며, 파일명은 바꿀 필요가 없다.

선택한 이미지는 게임별 런처 데이터 폴더에 사본으로 저장한다. 원본 이미지와
게임 폴더는 수정하지 않는다. 라이브러리와 상세 표지가 즉시 갱신되고 런처를
다시 실행하거나 원본을 옮긴 뒤에도 사본을 사용한다. **수동 이미지 해제**는
런처의 사본만 지우고 이전 Steam/GOG 선택 또는 자동 이미지로 돌아간다.
게임 경로를 바꿔 게임 ID가 달라지면 수동 이미지를 다시 연결해야 한다.

## 이미지 미리보기와 목록 표시·분류

라이브러리의 **이미지 미리보기**에서 **버튼으로만 / 마우스 올리기 / 마우스
오른쪽 클릭** 방식을 고른다. 각 이미지와 Steam·GOG 검색 후보의 미리보기 버튼은
선택한 방식과 관계없이 사용할 수 있다. 마우스 올리기는 잠시 기다린 뒤 열리고,
오른쪽 클릭과 버튼은 고정된 미리보기를 연다. 닫기 버튼·Escape·바깥 클릭·페이지 스크롤로
닫을 수 있다. 미리보기는 이미지 선택·표지 적용·게임 실행을 수행하지 않는다.
검색 후보는 해당 게임의 현재 검색 결과만 읽으며 동시에 새 미리보기 요청 두 개까지만
처리한다. 상품 연결에서 이미 확인한 이미지도 같은 확대 미리보기를 사용한다.

게임 행의 **⋯ 표시·분류 설정**에서는 다음 항목을 저장한다.

- **이 게임의 목록 섬네일 숨기기**: 목록에 이미지 태그·자동 이미지 요청·호버
  미리보기를 만들지 않는다. 상세 화면과 저장된 원본 표지 사본은 유지한다.
- **성인용 분류**: 미분류·일반으로 표시·성인용으로 표시를 직접 선택한다.
- **구매처**: Steam·Epic·GOG·itch.io·BOOTH·DLsite·DMM GAMES·FANZA·기타 중
  여러 곳을 직접 선택할 수 있다.

목록의 성인용·구매처 필터는 엔진·상태·검색·즐겨찾기 등과 함께 적용되며 재실행에도
유지한다. 기본은 전체 표시다. **성인용 표시 제외**는 직접 성인용으로 지정한 게임만
제외하므로 미분류 게임의 내용을 보증하지 않는다. 이 분류는 공식 연령 등급이나
보호자 통제 기능이 아니다. **구매처 미지정**으로 아직 정리하지 않은 게임도 찾을 수 있다.

직접 지정한 구매처는 **구매:** 배지로, 기존 상품 페이지 연결은 **연결:** 배지로
구분한다. 상품 연결·폴더 이름·게임 제목에서 구매 여부나 성인용 여부를 추측하지 않는다.
설정을 읽기 전이나 설정 파일 오류가 있는 동안에는 목록 이미지를 만들지 않으며,
손상된 설정 파일을 자동으로 덮어쓰지 않는다. 라이브러리 설정은 게임 파일과 별도로
런처 데이터에 저장한다.

## 브라우저 확장으로 상품 대표 이미지 가져오기

상품 연결용 웹 확장에서 대표 이미지 정보도 선택적으로 함께 가져올 수 있다.
지원되는 공개 상품 페이지에서 확장을 연 뒤 대표 이미지 읽기를 직접 요청하면
현재 문서의 `og:image`·`twitter:image` 메타데이터를 확인한다. 확장 자체는 이미지
파일을 내려받거나 원격 이미지 미리보기를 열지 않는다. 읽은 후보의 공식 이미지
주소를 연결 정보에 포함할지 사용자가 선택하고 복사하거나 연결 파일로 저장한다.
페이지에 후보가 없거나 허용하지 않는 이미지 주소면 상품 정보만 가져올 수 있다.

IndieDeck의 **스토어·브라우저 연계**에 해당 정보를 가져온 뒤 대상 설치 게임을
선택하고 이미지 미리보기를 직접 요청한다. 이때만 런처가 허용된 공급자 이미지
호스트에서 파일을 내려받아 검사한다. 미리보기와 별도의 적용 동작으로 표지를
저장하며, 상품 연결 정보 저장만으로 기존 표지를 바꾸지 않는다. 적용 대상은
현재 등록된 설치 게임이다. 상품명만으로 동명 게임이나 설치 버전을 추측하지 않는다.

적용한 표지는 수동 이미지와 같은 런처 데이터 사본으로 저장된다. 라이브러리와
상세 화면에 즉시 반영하고 다음 실행에도 사용한다. 이미 수동 표지가 있으면
사용자가 적용한 새 표지로 교체되며 **수동 이미지 해제**로 이전 스토어 선택이나
자동 탐색으로 돌아갈 수 있다. 게임 폴더·원본 이미지·스토어 계정 파일은 수정하지 않는다.

이미지를 포함하기로 선택한 연결 정보는 `schemaVersion: 2`와 `artwork: { url }`을
사용한다. 이를 처리하는 새 런처와 확장을 함께 사용해야 하며, v0.1.17 이하의
상품 연결 가져오기에는 이미지가 없는 기존 v1 연결 정보를 사용한다. 일반 상품
URL 붙여넣기는 페이지 DOM을 읽지 않으므로 대표 이미지 메타데이터가 추가되지 않는다.

Steam·Epic·GOG·itch.io·BOOTH·DLsite의 지원 상품 경로와 공급자별 이미지 주소
규칙을 사용한다. CDN 구조 변경, 접근 제한, 로그인·연령 확인, 이미지 크기·형식
제한 때문에 특정 페이지의 후보를 가져오지 못할 수 있다. 실패해도 기존 표지는
유지하고 파일 선택·드래그 방식으로 직접 넣을 수 있다. 이번 소스의 추출·검증·적용
흐름은 합성 데이터 검증과 실제 개인 브라우저 사용을 구분한다. 모든 공급자의
실제 상품 페이지에서 확장 활성화부터 표지 적용까지 성공했다고 뜻하지 않는다.

## 자동 탐색과 스토어 검색

게임 목록과 상세 화면에서 이미지를 보여준다. 수동 사본이 가장 우선이고,
사용자가 이전에 고른 Steam 또는 GOG
이미지가 있으면 이를 먼저 가져오려고 시도한다. 그 이미지가 없거나 가져오지
못하면 게임 폴더의 `cover.png`, `cover.jpg`, `cover.jpeg`, `cover.webp`,
`folder.png`, `folder.jpg`, `poster.png`, `poster.jpg`, `thumbnail.png`,
`thumbnail.jpg`를 정해진 순서로 살펴본다. 로컬 이미지가 없으면 Steam 설치
manifest의 설치 폴더 이름 또는 게임 폴더의 `steam_appid.txt`에서 AppID를
찾고 해당 ID의 Steam 공식 CDN 이미지를 요청한다. 일치하는 설치 manifest가
여럿이면 임의로 하나를 선택하지 않는다.

`steam_appid.txt`에는 개발·테스트용 ID나 다른 게임의 ID가 들어 있을 수 있어,
공식 CDN에서 받았다는 사실만으로 현재 게임과 이미지가 일치한다는 보장은
없다. 발견한 이미지가 잘못됐다면 게임 상세 화면의 **Steam 이미지 검색**에서
게임에 맞는 결과를 직접 고를 수 있다. 이 버튼을 누르면 게임 제목이 Steam에
전송된다. 결과의 이름을 확인하고 선택하면 그 게임에 대한 AppID가 런처의
사용자 설정에 저장되고 이미지가 표시된다. 표시된 이미지가 맞는지 확인해
준다. 선택하지 않은 검색 결과는 적용되지 않는다.

**GOG 이미지 검색**을 누르면 게임 제목을 GOG에 보내 후보를 검색한다.
이 경로는 GOG가 안정적인 공개 API로 문서화한 계약을 확인하지 못한 실험적
연결이므로 변경되거나 작동하지 않을 수 있다. 선택한 상품의 이미지 식별자만
저장하고, 재실행 시 GOG의 고정 이미지 호스트에서 다시 받을 수 있다. 다른
게임의 검색 결과나 사용자가 입력한 임의 주소는 선택 권한이 되지 않는다.

이미지는 실행 중 메모리에 캐시하며, 수동 선택한 식별자와 실제 이미지 파일은
다르게 취급한다. 다시 실행할 때 스토어 이미지가 필요하면 다시 가져와야 하므로
오프라인에서 이전 스토어 이미지가 보인다는 보장은 없다. 게임 폴더에 유효한
로컬 이미지가 있으면 네트워크 없이 표시할 수 있다. 네트워크 실패 시에는
로컬 이미지를 확인하고, 이미지가 없으면 기본 표시를 사용한다.

지원 형식은 PNG·JPEG·WebP다. 이미지 크기와 형식을 제한하며, 표시되는
출처는 수동 이미지, 로컬 게임 폴더, Steam 또는 GOG다. Steam manifest 읽기는 이미 발견한
게임의 이미지 식별에 사용하며, Steam 계정의 게임 목록 전체를 가져오거나
소유권을 확인하는 기능은 아니다.

## MTool과의 관계

Windows에서 사용자가 연결한 MTool은 RPG Maker MV/MZ·RGSS와 Wolf RPG,
Ren'Py, KiriKiri로 판정된 게임에 수동 전달할 수 있다. 실행파일을 MTool에
넘긴 후 게임 선택과 번역 진행·결과는 MTool에서 확인해야 한다. 이 연결은
개별 게임의 번역 성공을 보증하지 않는다. 공식 지원 엔진 및 사용법은
[MTool](https://mtool.app/)과 [공식 안내](https://mtool.app/tutorial.php?lang=en)를
참고한다.

Unity 폴더의 기존 MTool 흔적은 탐지될 수 있지만, 이는 해당 게임에 MTool
수동 전달이 지원된다는 뜻이 아니다. Unity 번역은 해당 게임에 맞는 별도의
번역기·로더 경로를 확인한다.
